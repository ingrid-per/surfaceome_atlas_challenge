# Decision log

Every choice that could change a result is recorded here **before** the result it
affects is produced. A threshold picked after seeing the output is a way of fitting
the answer; written first, it is a defensible method.

Append only. If a decision changes, add a new dated row and mark the old one
superseded — do not edit history.

| D20 | Minimum extracellular length for a surface call | Default **20 residues**. The **longest single extracellular segment** is stored for every protein as a numeric column, not just the pass/fail result. For GPI-anchored proteins the length is recorded as **not applicable**, never as 0 | Storing the measured length rather than only the verdict means Step 9 can re-run the 10 / 20 / 50 grid by re-reading one column instead of re-running the topology prediction, which is the expensive part. It also keeps the cutoff visible as a parameter rather than baking it into the candidate set. "Longest single segment" rather than total extracellular residues, because an antibody binds one contiguous exposed region — several short loops adding up to 20 residues do not make an accessible binding site. GPI-anchored proteins sit entirely outside the membrane, so a "longest extracellular segment" is not a meaningful quantity for them; writing 0 would make them fail a length filter they should never have been subject to, and writing their full length would make them look artificially strong. Supersedes proposal P1. | 2026-10-20 |
| D21 | How DeepTMHMM is run | Via **pybiolib**. First a pilot on ~50 proteins including the positive and negative controls; **check the licence terms before the full run**; then the full reviewed proteome in batches, in the background. If the service fails or the licence does not permit this use, fall back to **UniProt annotation only** and flag every affected protein | A pilot on known proteins catches a broken call format or a misread output before 20,431 sequences have been sent, and the controls show immediately whether the tool behaves as expected. The licence check comes before the full run because DeepTMHMM is academic-licensed and a bulk run is exactly the use a licence might restrict — better to find out at 50 sequences than at 20,431. Batching in the background keeps a long remote job from blocking the session and allows a resume rather than a restart. The fallback is explicit so that a service outage degrades the evidence visibly instead of silently: a protein with UniProt-only evidence can never reach tier S1, which requires two independent sources, so every affected protein must be flagged or the tiers would lie. Supersedes proposal P2. | 2026-10-20 |
| D22 | GPI-anchor evidence | **NetGPI** prediction **plus** UniProt's curated GPI annotation. The **source of every GPI call is recorded** (predictor, curated, or both). GPI-anchored proteins are placed in tier **S3**, and the report states how many are **predictor-only** | Transmembrane predictors miss GPI-anchored proteins entirely, because those proteins are tethered by a lipid rather than crossing the membrane. Mesothelin is the example that matters: a well-known target that a strict transmembrane filter would drop. Using a predictor and curated annotation together gives the same two-source structure as the transmembrane tiers. Recording the source per call is what makes the tier honest — a curated GPI call and a predicted one are not equal evidence, and lumping them together would hide which proteins rest on prediction alone. S3 rather than S1 because, even with both sources agreeing, GPI anchoring is weaker evidence of an accessible drug target than a confirmed transmembrane domain with a measured extracellular region. Completes proposal P2. | 2026-10-20 |

| D30 | SignalP dropped — **supersedes D24** | No separate signal-peptide predictor. Dropping it removes a tool, a licence, a request form and an environment at no cost to the evidence. | 2026-10-20 |
